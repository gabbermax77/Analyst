# Проект "Умный дом"

https://docs.google.com/document/d/14N6izsR1-zbOzMneBLbfUtXS8xZtNDApJee-vzhKaFk/edit?usp=sharing

В данном проекте необходимо было на основе интервью заказчиков и пользователей разработать:

- диаграммы потоков данных контекстного и логического уровня + ER-диаграмму;
- карту пользовательских историй с выделенным MVP, сценариями использования и критериями приемки
- словарь данных;
- прототипы приложения в виде сторибордов в Figma;
- ПМИ.

Использованный стек: DFD, ERD, User Story Mapping, MVP, acceptance criteria, Gherkin, Figma, ПМИ.

# Проект "Разработка функциональных модулей приложения"

https://docs.google.com/document/d/1vQ2dCiYpIlIJWQEp8tJS0BDRjmly47JYKD6OteLRxec/edit?usp=sharing

В данном проекте было необходимо разработать спецификацию требований к ПО для второго релиза мобильного приложения для обучения английскому языку:

- дополнить спецификацию функциональными требованиями для функции карточек для запоминания новых слов.
- подготовить требования к новой функции просмотра видео:
- обновить диаграмму UML Use Case;
- добавить новые табличные варианты использования;
- написать функциональные требования для функции видео, а так же атрибуты качества,бизнес-правила, глоссарий.

Использованный стек: FR, UML Use Case, Use Case.
